# T551M 屏幕界面

适配 320×480 触控屏，随 `devices/t551m/ui.py` 安装。上游为 Enceka/infoscreen
1.6.7，提交 `c9beb784e66ea5ac243e9bade78d5d9b0e962379`；`base/` 保留参与适配的
原文件及 MIT 许可，`stage.py` 从固定版本生成设备文件，重复执行结果一致。

## 使用

- 长按电源键约 1.2 秒，震动 80ms 并打开电源菜单：关机、重启、切换到 Android。
  选择后再次确认才执行；Android 切换复用现有启动选择器，将 Android 设为默认并重启。
  锁屏、息屏和应用内均可呼出；松手不再额外息屏，短按松手保持亮/息屏切换。
  菜单不显示固定机型标签，屏幕详情和网页看板的设备型号均读取系统 board 信息。
- 信号页顶部为运营商、网络制式和频段横排：前两项同字号，频段稍小；卡片减少纵向留白。
- 默认显示顶部状态栏、标题工具栏和 52px 底部导航（概览、信号、流量、短信、设置）。
  五个位置均可独立选择九个页面中的任意一个；再次点击当前页的底部入口返回其顶层。
  顶部菜单始终可访问所有九个页面；
  展开/收起有过渡动画。主屏使用较大数字与深色卡片。
- 屏幕内“设置 → 底部导航”单独配置五个底部入口，网页“服务 → 信息屏应用 → 底部导航”亦可调整。
- 屏幕内“设置 → 界面与锁屏”调整显示大小、状态栏、底栏、主题色、密度、动画、锁屏信息和上滑距离。
  网页“服务 → 信息屏应用 → 信息屏设置”也提供这些选项。
  显示大小为 85% / 100% / 120% / 140%，同时改变文字、图标与控件；密度另外控制留白。
  页面宽度、触控坐标、二维码保持物理像素布局，较大的内容纵向滚动。状态栏与锁屏时钟限制尺寸，保证窄屏完整显示。
  内置计算器已移除，其他应用保留。
  音量等数值设置使用独立的数值、加减、保存区域，间距 14px。
  电话插件加载时附加设备样式：拨号键至少 44px，数字与字母保持居中，
  通讯录等超出窗口的内容纵向滚动；不改插件的呼叫逻辑或联系人数据。
  音量条位于锁屏、工具栏和插件之上；音量按键仅调节档位，不播放提示音。
  设置分类、选项和操作使用统一线条图标，按设置 ID 映射、随明暗模式配色；选择项右侧显示勾选状态。
  AT 列表采用名称/指令上下排列，执行结果区分命令与等宽输出；长行自动折行，保留原始换行，重试按钮独立留白。
  设置、短信详情和应用列表使用统一块间距；长设备名、版本和温度在大字号下换行，通知弹窗避开上下导航。
- 网页“服务 → 信息屏应用 → 屏幕壁纸”分别上传桌面/锁屏背景，先预览再应用，或恢复默认。
  浏览器将 JPG/PNG/WebP 居中裁剪为原生 320×480 PNG；设备验证尺寸、CRC、数据长度与解压上限。
  上传与预览使用 12KiB 二进制分块（base64 16KiB），避免大图片触发 HTTP/ubus 请求限制。
  上传中显示进度，全部数据验证成功后才替换壁纸；临时上传限制数量并清理过期文件，重复块可安全重试。
  图片保存在 `/etc/e5-infoscreen/wallpapers/`，仅本机屏幕与经过认证的 LuCI RPC 可读取。
  更换后随下一次状态刷新生效，不重启屏幕；固件升级保留目录。
  “界面与锁屏”及网页“信息屏设置”支持暗色/亮色外观；亮色同时调整文字、图标、锁屏和电话的配色。
  卡片不透明度默认 70%，屏幕以 5% 步进调整，网页可填 0–100%；仅影响有壁纸的背景，
  覆盖列表、导航、菜单、弹窗、电话和锁屏信息卡。保存后自动刷新，重启后保留。
  文字、图标与二维码保持原有清晰度；恢复默认壁纸时恢复实色样式，已打开的电话界面也随设置更新。
- 国内四家运营商的常见名称按中英文映射，其他运营商原样显示。
- 今日、自然月用量与看板共享 `unisoc.traffic` 的 `today_used` / `month_used`，
  遵循上下行/仅下行/仅上行计量设置，统一 1000 进制及两位小数；约十秒刷新一次。
  套餐周期校准仍与自然月历史分开，与看板一致。锁屏速率来自蜂窝接口的实时字节差值。
  锁屏及主页实时网速默认比特模式：字节/秒 × 8 后按 1000 自动进位为 bps / Kbps / Mbps / Gbps。
  “界面与锁屏 → 网速单位”及网页“信息屏设置”可切换字节模式，按 1024 自动进位为 B/s / KB/s / MB/s / GB/s。
  保存后立即同步并持久保留；旧版选项自动兼容到对应模式。流量累计量不受此选项影响。
- 热点二维码保留黑白颜色与静区，导航图标的 SVG 描边不再影响二维码。

## 锁屏与触控

首次进入、息屏再唤醒时默认锁屏。单指从下半屏（55% 高度以下）向上滑动，
位移跟手；普通拖动达到 24% 屏高（最少 100px）解锁。“更长”使用 34%。
最近约 100ms 的上滑速度用于计算减速后的惯性行程，快速上滑最少 55px（更长模式 85px）
可顺势解锁；停止再松手不保留惯性，反向拖回取消解锁。离屏动画根据剩余距离和速度持续 140～320ms。
滑动需持续 70～2500ms、以竖直方向为主；横移过大、多指、取消、慢速短滑都会回弹。
亮屏后保护 400ms，解锁后拦截 450ms 合成点击，避免穿透到底层按钮。
动画只改变 transform/opacity。它是防误触锁屏，不是密码认证。

`t551m-screen-power` 在同一 flock 中协调背光与内核输入 `inhibited`：
先禁用触控再息屏，亮屏前恢复触控；用户显式设置 touch=0 时保持禁用。
独立 procd 守护进程每 100ms 校正外部背光变化，监听配置变化，并在退出后自动重启。
前端同步实际背光状态，防止外部亮屏后仍停留在旧的黑屏遮罩。
不解绑、不重置、不刷写触控芯片；电源/音量等实体按键保持可用。
用户主动关闭触控时，锁屏允许实体确认键两次确认；网页设置也能重新开启触控。

## 详细信息加载

元数据与无线查询分离：API 立即返回设备与基带资料，`t551m-screen-details` 在后台通过
已有 nr6/nr7 AT owner 并行读取六项信息，不打开串口，不占用 nr2 交互通道，也不修改模组设置。
缓存有效期 30 秒，flock 防止重复采集；前端在刷新期间每 800ms 读取结果，离开页面停止补查。
失败字段显示未知，不会误报为未锁定；再次进入先绘制已取得的内容。
实机首响应由约 2608ms 降至 189～208ms，后台刷新全部完成约 668ms（当次测量，随通道负载变化）。

## 验证与维护

Linux 上运行 `test_screen.py`（四项背光/触控次序测试）与 `test_wallpaper.py`
（八项图片/分块验证测试）。`test_screen_browser.py` 使用 Playwright Chromium、原生尺寸页面
及本机 API 快照，验证手势、防误触、导航、菜单、语言映射、数字格式、二维码样式和设置。
新增快速短滑、停住、反向取消、重复点击返回、五入口自定义与四档尺寸不横向溢出的验证。
电源菜单测试覆盖短按松手、长按只震动一次、息屏/锁屏、应用 frame、失焦取消、确认/取消、
三个动作的 API 请求及失败重试；信号卡片验证横排、字号比例和最大显示尺寸。
实体拨号键测试覆盖打开电话、重复按键保留号码、锁屏防误触，以及从概览、设置、应用列表
进入后点击顶部返回。返回仅恢复当前页的焦点（禁止浏览器自动滚动），关闭时清除 iframe
加载回调；应用导航后按新的 document 重新绑定实体按键，避免复用 WindowProxy 漏绑。
`test_screen_details.py` 验证只读请求、忽略异步上报、查询错误与超时的未知值处理。
API 快照与截图包含设备数据，不纳入 Git。

实机验证：WPE 截图中的热点二维码可被 ZXing 解码；息屏下注入触控事件无法送达 evdev
读取者，亮屏恢复投递；外部背光改写亦恢复正确状态。LuCI 壁纸上传、页面重载保留、
390px 布局和恢复原图通过，测试图片完成后清除或恢复原图。
另以约 529KB 难压缩图片验证锁屏和桌面上传、重载预览，单次请求最大约 16.6KB，无浏览器中断。

这是固定上游版本的设备适配。后续更新信息屏应同步更新 `base/`、适配锚点和测试，
避免直接安装原版信息屏包覆盖 T551M 的界面文件。
